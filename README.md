# Variedades Yesica ✨

## Descripción del proyecto

Variedades Yesica es una página web creada para un pequeño
emprendimiento de venta de ropa desde casa. Su objetivo es mostrar los
productos disponibles, sus precios y facilitar a los clientes la
realización de pedidos por medio de WhatsApp.

## Objetivo

Desarrollar un sitio web Front-End moderno, atractivo y adaptable a
diferentes dispositivos, que permita visualizar un catálogo de prendas
de vestir y realizar pedidos de manera sencilla.

## Tecnologías utilizadas

-   HTML5: estructura de la página web.
-   CSS3: diseño, colores y estilos.
-   JavaScript: funciones e interactividad.
-   Visual Studio Code: editor de código.
-   GitHub: almacenamiento y publicación del proyecto.

## Características principales

-   Página de inicio.
-   Catálogo de productos.
-   Categoría de blusas.
-   Categoría de bermudas.
-   Categoría de pantalones.
-   Visualización de precios.
-   Carrito de compras.
-   Botones para agregar y eliminar productos.
-   Envío de pedidos directamente a WhatsApp.
-   Diseño adaptable a celulares y computadores.

## Instalación y ejecución

1.  Descargar o clonar el repositorio.
2.  Abrir la carpeta del proyecto en Visual Studio Code.
3.  Verificar que las fotografías estén dentro de la carpeta `imagenes`.
4.  Abrir el archivo `index.html`.
5.  Ejecutar el proyecto con Live Server o abrirlo directamente en el
    navegador.
